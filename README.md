## Projects

**[Handwritten digit recognition](https://github.com/SakariaAhmed/Neural-Network-MNIST)** · [Live demo](https://linux-lab.tail15c91a.ts.net/)<br>
Draw a number and a neural network tells you which digit it sees. A TensorFlow model served by FastAPI, packaged with Docker and hosted on my own server.<br>
<sub>Python · TensorFlow · FastAPI · Docker</sub>

**[Linux homelab](https://github.com/SakariaAhmed/Linux-Homelab)**<br>
The Ubuntu server that runs the demo. Its containers are defined in Terraform and monitored privately with Prometheus and Grafana. I use it to practise rollbacks and restoring from backup.<br>
<sub>Linux · Terraform · Docker · Prometheus · Grafana</sub>

**[QR Studio](https://github.com/SakariaAhmed/QR-generator)** · [Open the app](https://sakariaahmed.com/tools/qr/)<br>
Make QR codes for links, text and Wi-Fi. Everything is generated in the browser, so nothing you type leaves your device. Exports PNG and SVG, and comes with a Python CLI.<br>
<sub>JavaScript · Python</sub>

<sub>The live demo runs on my homelab, so it's occasionally offline.</sub>
